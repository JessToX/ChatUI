# 可运行的对话组件

这些资源提供具体结构、主题样式和交互实现，用于当前宿主已经提供的内联执行能力。它们本身不会注册工具、自动启动插件、修改 ChatGPT 页面或开启 DIL。普通聊天若只支持 Markdown，不能将代码直接贴进回答并声称已经显示组件。

## 使用顺序

已连接 Renderer 时优先按 [工具契约](renderer.md) 调用；组合讲解可以在 `render_explanation` 的 `component` 块复用这些类型，或以结构化 `diagram` 表达模板之外的关系。以下 HTML 组装路径用于真实可用的替代执行通道，不必为每轮读取全部模板。

1. 先读取当前宿主实际提供的可视化技能及展示说明。有HTML/JavaScript执行能力时使用下列交互模板；没有时继续检查计算绘图与图片展示，受力任务转到 [静态绘图路径](physics.md)，不要因此直接认定不能画图。
2. 根据本轮内容，从 [示例配置](../assets/component-examples.json) 选择一种类型。只取相关组件，不能把全部示例整页输出。
3. 有文件工具与执行器时，使用 [组装脚本](../scripts/compose.py) 将当前经过核对的配置写入对应类型的小型自包含模板（逐类型链接见下表）；脚本负责唯一根ID与JSON安全转义。先读取脚本帮助，按当前宿主授权路径生成片段，不要求用户手动运行。若当前执行通道不支持该脚本，则只读取本轮类型对应的模板，按下面相同转义原则替换 `script#chatui-component-config` 中的JSON数据，再交给实际可用的执行通道。配置只是数据，运行逻辑与样式保留在模板中。每个独立模板均小于50,000 UTF-8字节；不需要读取包含全部类型的大文件。
4. 将完成的片段保存到当前宿主授权的持久输出位置，再使用该宿主现行说明中的展示机制。不要把本地路径或某个宿主的显示标记写回这个跨宿主插件。
5. 在解释对应位置显示组件：先交代要观察的问题，随后放相关组件，继续用自然 Markdown 解释。下一轮根据需要更新相关组件，短答及完整正文仍用正常文字。

模板无 API 请求、外部脚本或外部字体；包含可选择文本与 MathML。只有 `media-panel` 会按配置尝试显示经过核对、宿主允许的远程图片；原始来源保留，显示受限时不代理或重新托管。根元素及配置元素的 ID 是模板内部绑定，不是宿主 API。如果一个 HTML 片段中确实需要两个独立实例，应为每个实例及其 CSS/脚本查询同步更改 ID；通常应输出两个分别聚焦内容的片段。

开发维护时，这些小模板从唯一 [组件源文件](../assets/component-kit.html) 构建，运行逻辑只修改该源文件；生成回复时仍按以上步骤复制对应模板并替换配置。源码仓库的 `scripts/build_component_templates.py` 负责重建，`--check` 与打包校验会拒绝遗漏或过期模板。

## 数据入口

每个配置是 `{schemaVersion: 1, contentId, type, title, data}`。

- `contentId` 标识本次数据快照。修改题目、参数、标签或含义时更新内容身份，并通过当前展示通道重新提交完整最新配置；正文不会刷新旧卡。运行时另外计算整个配置的指纹，防止错误复用旧状态。
- `title` 为可选短标题，不重复用户整段问题。
- 使用真正的 JSON 序列化器，禁止用字符串拼接把外部文本写入脚本。将序列化 JSON 中的 `<` 替换为字面转义 `\u003c`，防止用户文本中的关闭标签提前结束 JSON 脚本元素。所有运行时文本通过 `textContent` 写入，不作为 HTML 解析。
- 示例全部为虚构、公开常识或通用教学数据，实际使用时替换数据，而非声称用户拥有示例进度或已完成示例题目。

| `type` | 必需数据及实际行为 |
| --- | --- |
| [`progress`](../assets/components/progress.html) | 多阶段：`total, stages[{id,label,value,subsetOf?}]`，共用可选 `unit`；单阶段兼容 `value,total,label?`。`value` 与 `stages` 互斥；可选 `note,details[]` 文本说明。每个已知阶段分别画条，`0 ≤ value ≤ total` 且 `total > 0`；包含阶段不相加成总完成率。 |
| [`timeline`](../assets/components/timeline.html) | `items[{date,title,detail,status,tone}]`；可选 `note`。显示编号与连续细轨；缺失日期明确为未知。 |
| [`profile`](../assets/components/profile.html) | `name`；可选 `eyebrow,subtitle,tags[],summary`。用于用户确认或明确标为提案的风格档案、概念画像。 |
| [`comparison`](../assets/components/comparison.html) | 一至四个 `items[{label,tone,title,math,mathLabel,detail}]`。两列自动向窄屏单列重排；一个绿色项目可作为已核验结论块。 |
| [`steps`](../assets/components/steps.html) | `items[{title,math,mathLabel,detail}]`；可选 `note`。编号步骤与公式；长推导仍放在正文。 |
| [`rhythm`](../assets/components/rhythm.html) | `items[{label,emphasis}]`；等级只能为 `brief / moderate / focus`。横条表示定性编辑建议，固定明确声明不是测量值或字数配额。 |
| [`quiz`](../assets/components/quiz.html) | `questions[{id,prompt,options[{id,label}],correct,explanation}]`。提交前不显示答案，提交实际评分；缺题时提示补答；重试清空答案和反馈。 |
| [`geometry`](../assets/components/geometry.html) | 正数 `radius`；可选 `heightRatio`（0.05–1.95，默认 1.5）和 `unit`。显示精确圆内等腰三角形，滑块同步高度、半底边和面积。 |
| [`answer`](../assets/components/answer.html) | `title`；可选 `label,math,mathLabel,detail`。绿色细边框、结论标题与真实公式；默认标签为“结果”。只有核验后才能标注“正确”。 |
| [`line-chart`](../assets/components/line-chart.html) | `xLabel,yLabel,seriesLabel,points[{x,y}]`；可选 `xUnit,yUnit,tone,note`。一条数值曲线，2–80 个有限点，坐标绝对值不超过 10¹²，x 严格递增。轴/系列名称最多80字符，单位最多24字符。轴域由数据计算，保留负值并使用易读刻度；可展开数据表核对数值。 |
| [`force-diagram`](../assets/components/force-diagram.html) | 数值模式：`body,unit:"N",forces[{id,label,fx,fy,tone}]`；可选 `axisAngle`、`note`。1–12 个真实力，全局右/上分量绝对值不超过 10¹²；统一尺度画箭头、给力表，可开关合力与所选力在局部轴的分解。方向模式：`mode:"direction",body,forces[{id,label,angle,tone}]`，省略 `unit`；只画等长方向箭头，明确大小未知，无数值合力/分力控件。 |
| [`motion-lab`](../assets/components/motion-lab.html) | `initialVelocity,acceleration,duration`；可选 `time`、`unit:"SI"`。一维匀加速、x(0)=0；v₀范围−100至100 m/s，a范围−50至50 m/s²，时长0.1至60 s，当前时间在时段内。三个滑块同步位置、速度和独立的x(t)/v(t)图，支持恢复初始参数。不能套用于变加速或有空气阻力的原题。 |
| [`tabs`](../assets/components/tabs.html) | 2–6个 `items[{id,label,body,title?,points?}]`；可选 `note`。切换不同视角的真实内容，支持键盘方向键、Home/End及有效状态恢复。不是展开全部比较所必需信息的唯一入口，重要差异可直接用并列对照。 |
| [`reveal-steps`](../assets/components/reveal-steps.html) | 1–12个 `items[{title,detail,math?,mathLabel?}]`；可选 `initialVisible`，默认1。下一步、上一步、恢复初始展开均实际更新；展开数不等于掌握程度。适合用户需要循序理解时，完整推导请求仍直接展示全文。 |
| [`data-table`](../assets/components/data-table.html) | `columns[{key,label,type}],rows[{id,values:{key:value}}]`；可选 `filterLabel`。2–8列，1–100行；列类型为 `text` 或 `number`。真实搜索、文字/数字排序、匹配数和重置，数字不会按字符串顺序排序。简单小表仍优先Markdown。 |
| [`media-panel`](../assets/components/media-panel.html) | 1–6个 `items[{title,body,alt,sourceUrl,sourceLabel,imageUrl?,caption?,credit?}]`。图片与解释并排，窄屏上下排列。来源与图片仅接受HTTPS；图片未加载前和失败后保留来源说明，成功后显示图片。只在宿主允许图片来源时传imageUrl；原生图片通道优先。 |

多阶段进度支持1–12项，按输入顺序显示。`id` 非空且唯一、最多80字符，`label` 非空、最多160字符；`subsetOf` 为已知父阶段的id，必须指向另一个已列阶段、不能成环，子阶段数量不大于父阶段。不猜测阶段包含关系或具体条目身份。更新时传入完整总量及全部已知阶段，包括未变化者，不能仅靠正文更新旧卡。

`tone` 仅接受 `blue / green / orange / neutral`，未知值回到蓝色。颜色不能代替标签。进度含义未经核实时，不使用绿色组件来暗示已核验完成。

## 公式

`math` 使用结构化 MathML 数据：例如分数写成 `{"tag":"mfrac","children":[{"tag":"mi","text":"k"},{"tag":"mi","text":"m"}]}`；`mathLabel` 提供可读描述。

支持 `mrow, mi, mn, mo, mtext, mfrac, msup, msub, msubsup, msqrt, mroot, mover, munder`。不会执行公式字符串，不接受任意标签、属性或 HTML。嵌套最多十六层。只在组件内放紧凑公式；长等式拆成步骤，或用正文数学排版，不把长公式挤到窄屏。

## 真实交互与状态

测验在浏览器内按实际选项评分。正确答案存在组件代码中，因此适合学习反馈，不是隐藏答案的考试安全方案。首次展示未作答，完整提交后显示解释、真实分数和重新测试按钮。首次展示的相邻正文同样不泄露正确选项或推导，不用本题正确选项组合举例说明回复格式；直接提示选择后提交即可。

只有宿主实际暴露 `sendFollowUpMessage` 且配置提供 `followUp` 时才显示继续对话按钮。请求包含真实选择和得分。发送失败保留本地结果，并明确没有确认消息送达；不得伪造“已开始下一课”。宿主确认对话、取消和可用性仍遵循其当前规则。没有桥接能力时，用普通用户消息继续。

存在 `setWidgetState` 时，交互结束后保存有界 JSON 快照。私有状态包含配置指纹，只恢复同一内容下有效的选项或几何参数；得分从真实答案重新计算，不相信缓存成绩。收到宿主状态事件也进行同样检查。保存失败不妨碍当前局部交互，且不宣称跨客户端一定持久保存。传给模型的状态可能延迟或缺失；只有实际收到的状态或用户消息能成为后续事实依据。

几何组件取圆心 O=(0,0)、顶点 A=(0,r)、底边高度 y=r−h，半底边 `x=√(2rh−h²)`，面积 `S=xh`。B、C始终位于圆周上。D是底边中点，接近O时省略D标签以避免重叠。滑块范围避免退化三角形，不能把这个组件当作任意几何图形或任意公式计算器。正文可继续推导面积最大时 `h=3r/2`。

受力图为二维质点模型，`body` 和每个 `label` 最多120字符，非空唯一 `id` 最多80字符，`note` 最多1000字符。数值模式的单位固定为牛顿，其他单位先正确换算。`axisAngle` 与方向模式的 `angle` 都以度为单位，在 −360° 至360° 内；0°为向右、90°为向上。数值模式的输入始终是全局分量，`axisAngle` 只转动分解基底，不改变真实力。默认隐藏合力与分力，只有所选真实力被投影；虚线分力不加入合力。图中编号连接力表，零向量没有假箭头。未知大小使用方向模式，不把大小猜成1 N。物理判断及更新条件见 [物理图解](physics.md)。

## 外观与可视验收

独立 `cui-` 类对应用户指定的参考外观：约18px圆角、1px细描边、18–22px内边距、透明外层；桌面正文18px，窄屏16px，数字和关键标题进一步突出。不覆盖宿主 utility。正文和底色跟随宿主，蓝绿橙强调色使用明暗自适应的专用配色，避免被宿主偏淡的色值冲淡。文字强调色与曲线、描边、进度条的标记色分开，兼顾鲜明程度与小字对比度。

颜色各有用途：蓝色表示比较或概念结构，绿色表示定义清楚的进度或已核验结果，橙色提示待核对信息或几何重点。段落保持中性色，不给每行随机上色，不添加装饰渐变、发光或大面积彩色背景。组件的外观可控范围只限其内联区域，不能修改整个聊天软件的排版或主题。

这是有明确截图偏好的组件样式。普通图表、长正文及无需框选的信息不自动套容器，也不将组件边框扩展到整个回答。

每次内容变化后检查数据、公式、标签与实际图形一致。至少验证：

- 普通 Chat 全程不 @ 的新对话能否选用并真正显示组件；模板文件存在不算通过。
- 深浅主题及360px宽度下没有文字裁切、并列溢出、不可见控件。
- 多阶段6/10、3/10改为7/10、3/10时，通过新快照同步数值、条宽与口径；未变化阶段保留，包含关系不合计为总完成率，没有历史数据混入。
- 两题测验答对一题实际显示1/2；缺题无法提交；重试清空；宿主不提供桥接时没有继续按钮。
- 几何滑块取h/r=1时x=r、S=r²；取1.5时x=√3r/2、S=3√3r²/4；图与数值同步。
- 折线图的横纵坐标、单位、符号和数据表一致；常量序列及跨零数据仍可读。数据异常时明确提示，不能显示貌似有效的曲线。
- 受力图 `(3,4)` N 大小为5 N；水平力6 N和−2 N、竖直力20 N和−20 N合为 `(4,0)` N。30°局部轴下重力 `(0,-20)` N 投影为 `(-10,-10√3)` N，开关分力不能改变合力。方向模式没有假造数值。
- 匀加速实验按x=v₀t+at²/2与v=v₀+at联动，转向时刻和负速度正确；切换时间不改变给定参数的解析曲线。重置恢复题给初值。
- 视角切换、分步展开、搜索排序均改变真实显示内容；操作不能自行成为向对话发送的消息。图片加载失败不留下空白，来源不可编造；本地模拟加载事件仅测逻辑，不证明远程照片已显示。
- 刷新恢复只使用同内容身份的有效状态；改变问题或参数后不恢复旧答案。

分别记录自动选用、组件真实显示、样式接近程度与交互行为。当前执行环境的模板预览通过，不等于普通 Chat 的自动加载或原生DIL已通过。
