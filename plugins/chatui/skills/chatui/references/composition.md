# 内容组合：先保证阅读连贯

默认先给连续、自足的原生讲解；只在图形或交互确实帮助理解时用 `render_response` 补充必要的局部视图，简单回答无需工具。保留的 `render_html`、文档与组件入口用于适合其能力或用户明确要求的内容。以下块组合规则专用于结构化辅助视图，不要求把整轮正文搬入 iframe。

| 内容关系 | 适用表达 | 不能混淆 |
|---|---|---|
| 连贯解释／故事／分析 | prose、heading、list、quote、code | 不能强套教学模板或每段加卡片 |
| 公式与差异 | math、comparison、parallel group | TeX 只描述公式，不描述样式 |
| 历史／步骤 | timeline、steps、reveal-steps | 编号先后不意味着已经完成 |
| 完成状态 | progress、清单 | 分母和包含关系必须真实 |
| 定性节奏 | rhythm | 横条不代表实测百分比 |
| 数值变化 | line-chart、适用的 motion-lab | 先确认数据和单位，不用任意表达式 |
| 空间／因果 | diagram、geometry、force-diagram | 坐标、点线面、标签与题设保持一致 |
| 自测 | quiz | 只对实际提交计分，不在前文泄露答案 |
| 补充材料／多个视角 | collapse、tabs | 默认内容不藏在层层折叠里 |

正文 → 必要的组件 → 正文，不规定图文比例。`group.layout:"parallel"` 仅用于需要同时比较的内容，窄屏转纵向。外层透明、无整篇大边框、导航或仪表盘；卡片只包有意义的关系或答案。

共享事实是数值、单位和重复标签的唯一来源。`{{id}}` 为带单位可读数量，`{{id|value}}` 用于 TeX 数值，`{fact:"id"}` 为组件数值引用。引用只展开一次，不执行计算表达式。先核对派生量再写入事实，不因布局需要制造值。

同一快照保留稳定块标识；题设改变用新快照。工具生成的同源文本用作失败兜底，不由模型再写一遍。原生引用与文件保留必要衔接；不能控制宿主把 iframe 插到任意原生段落中。

详见 [工具契约](renderer.md) 和 [十组样例](response-examples.md)。
