# 连续呈现与状态

自然追问先依据题目、指代和知识点作答；“为什么”不自动绑定到最后一次参数操作。默认连续、自足的原生讲解，需要辅助图形时才用 `render_response`，无需用户重新 @。显式“按当前条件”追问只有在来源快照、图块和修订匹配且状态可确认时采用探索值；缺失或冲突时说明不确定并核对条件。宿主接收回执不能证明模型采用，视图操作不自动发送消息、重答或调用工具。

## HTML 生命周期

HTML内容或条件变化用新 contentId。重复接收同一结果和主题切换不重建DOM、不重置折叠；HTML与结构化切换清理旧挂载和回调。本版HTML不持久保存跨会话展开状态，展开也不生成模型操作证据。

## 结构化路径的不可变题设快照

- 改质量、g、角度、分母、阶段、题目或条件：重新核对派生量，使用新 `contentId` 和完整相关 `facts`。历史卡片仍是旧题设，不能口头声称已经更新。
- 同一快照仅补充或调整本轮内容时保留稳定块 `id`。未变块的 DOM 与控件状态保留，变化块单独重建；局部更新不销毁全页、不重置所有答案。
- 刷新恢复同时检查快照身份和块指纹。不恢复其他题目的作答；用户重试测验后清除本次答案和分数。

## 操作不是推断

测验提交、状态切换、实验滑块、展开、表格筛选和排序只有在真实操作时才报告。服务与渲染器不保存整段聊天；匹配的私有 widget state 可恢复控件。恢复的 modelContent 不被当作新的真实操作证据。

模型只有实际收到宿主回传或用户说明才引用操作。“已展开”不等于“学会了”，筛选不等于最终选择；实验参数只影响本地实验读数，不自动改写题设、固定正文或推导。想把实验值设成新题设，需要明确新一轮快照。

## 本地与需要推理的动作

选择、计分、重试、展开折叠、标签页、图表提示和注册实验计算在浏览器内完成。需要新解释或新题目才发后续消息。不支持发送时给可复制问题；未确认发送时提示先检查重复，不把失败标为成功。未提交测验不计分，提交前不泄露答案。

## 失败和速度

无工具或一次修正后仍失败，直接完整文字兜底，不循环重试。工具生成同源可读文本；视图错误安全展示文字。当前结果未完整到达不假装逐 token 流式；首屏和本地反馈与模型、宿主、网络等待分别测量。真实连续聊天是否自动调用必须保留记录，不能从 Skill 配置推算路由率。
