# Intellectual UI / UX — Phase 2A

日期：2026-10-11。设计定位：**ChatUI — An Intellectual Interface for AI Conversations**；**Designed for understanding, not just displaying.** 本规范服务于 G01 数学、G04 论证比较、G05 长文阅读三个纵向原型，以及 G06 原生短答对照。执行范围、独立数学 oracle 和 B1 硬门槛沿用 [Phase 0–1](phase01.md)、[B1](b1.md)、[既有视觉规范](../visual-spec-v0.7.md)及 [Rich Document 契约](../rich-document-v1-spec.md)。

## 1. 阅读顺序与内容层次

阅读面是一篇连续文档。先给读者问题、适用条件与必要定义，再推进理由、推导、观察和结论；实验是在相邻正文已经说明的条件下操作的独立对象。使用标题、编号、明确词语和少量强调区分层次。颜色只能重复已有文字含义，不能承担唯一的意义。

- 数学：题设与单位 → 固定推导 → 最优结论 → 当前实验 → 边界与自检。G01 的 `r=2 cm` 和固定最优条件不随滑块重写。当前读数必须标明是实验状态。
- 哲学：合成问题 → 事实假设与价值判断 → 两组前提、理由及推论 → 指向具体推论的反例 → 尚未解决的问题。编号使“这个反例反驳什么”有明确目标。
- 研究：合成声明与摘要 → 八个章节 → 证据编号与方法 → 结果 → 解释范围及限制。表格、公式和代码附属于所在论证；不能把合成证据包装成外部研究引用。
- 原生对照：短答、简单确认、明确 Markdown 请求直接展示原生内容。G06 是使用条件的对照，不新增组件或改变生产路由。

## 2. 排版与空间 token

样式唯一入口为 `renderer/lib/document.css`，仅文档资源加载，选择器均位于 `.cui-rich-document` 范围。继续使用可信 compositor、既有组件和生成器；字体继承宿主系统字体，外层保持透明。

| Token / 对象 | 桌面值 | ≤560 CSS px | 用途与判断 |
|---|---:|---:|---|
| 阅读最大宽度 | 780px | 可用宽度的 100% | 限制连续正文行长；不添加第二层页面壳 |
| 正文 | 18px / 1.7 | 16px / 1.7 | 中英文、公式相邻的连续阅读 |
| 标题 h1 / h2 / h3 | 28 / 24 / 20px | 28 / 24 / 20px | 用层级、间隔与语义区分，不用各自一张卡 |
| h4 | 18px | 18px | 小节标签，不冒充主标题 |
| 辅助说明 | 15px / 1.7 | 14px / 1.7 | 提纲、复制状态；不用弱对比度隐藏限制 |
| 展示公式 | 26px | 22px | 放在正文流，超宽时区域内滚动 |
| 代码 / 表格 | 16px | 14px | 数据密度优先，同时保留局部滚动 |
| 间距 | 8 / 12 / 16 / 24 / 32px | 同组 token | 8 为紧邻项；12 为辅助关联；16 为段间；24 为独立块间；32 为同一正文块内新标题前总间距 |
| 独立面板 | 1px 中性边框 / 18px 圆角 / 24px 内边距 | 18px 内边距 | 实验与比较内容有边界，背景透明 |
| 控件目标 | 最低 44px 高 | 最低 44px 高 | 按钮、滑块、选择器及折叠 summary |
| 可见焦点 | 2px 蓝线 / 3px 外偏移 | 同左 | 输入、按钮、summary、链接及可滚动区域 |

文字使用既有 `--cui-fg`，背景参考既有 `--cui-bg`，细边使用 `--cui-line`，辅助文本使用 `--cui-muted`。蓝色 `--cui-blue` 表示可探索关系或重点，绿色 `--cui-green` 表示结论，橙色 `--cui-orange` 表示当前条件和限制。深浅色值来自既有主题 token；不得硬编码白色正文背景来遮住宿主。

标准主题的普通文字对比度目标为至少 4.5:1、大字至少 3:1。宿主可覆盖主题变量，因此标准预览的对比度结果只证明被测深浅主题；不声明任意外部颜色组合均通过。

## 3. 卡片使用与禁用规则

**使用卡片：** 有自己状态、控件和读数的实验；需要同尺度逐项比较的两种立场；单独完成并获得反馈的测验；有独立描述和操作范围的图解。卡片内应能回答“这组内容为什么需要一起看或一起操作”。比较项等宽并列，≤560px 按正文顺序纵向排列。

**不用卡片：** 普通段落、每一步固定推导、单独公式、普通标题、表格前的解释、来源编号和章节导航。结论、假设、反例与限制采用明确标签及左侧细线 callout；背景透明，没有整块底色。折叠以细分隔线和原生 disclosure 呈现，不套进另一张卡。

可访问性信息不依赖卡片外观：有标题和标签才有认知边界，改变背景色不等于给出了对象名称。外层不绘制聊天侧栏、输入框、浏览器外壳或浮动导航。

## 4. 真实交互与诚实反馈

### 几何实验

复用已有 geometry 运行时。滑块 `h/r` 的允许区间是 `[0.05,1.95]`；解析端点 `h=0,2r` 为退化条件，不宣称滑块可以达到。键盘左右方向键修改高度时，图形、当前高度、底边、面积和单位应同步改变；最优条件文本始终是 `h=3 cm`、`b=2√3 cm`、`A=3√3 cm²`，分别用短公式呈现。圆外尺寸线标明完整高度 `h=AD`；`r`、`h−r`/`r−h`、半底边 `x` 与底边 `b=2x` 分清。当前经过舍入的读数使用 `≈`，朗读使用“约”，不将显示精度写回数值状态。重置必须恢复真实初始状态，不仅替换可见读数。

拒绝整个允许区间内不可可靠表示的半径。下溢值、非有限值或非法单位不得通过改文案或夹取结果掩盖。错误应可读、停止无效挂载，并且不保存错误零面积；这是 B1 数值安全门槛。

### 折叠、比较和 tabs

用原生 `details/summary` 承担补充推论、反例或方法细节；正文说明其主题，展开后内容在同一阅读顺序中出现。比较静态卡片不设置假按钮。立场的前提、理由、推论分别成行，使用现有纯文本 detail 字段与 `pre-line`，不解释模型提供的 HTML；窄屏按 A → B 的 DOM 顺序阅读。tabs 只用于真实内容切换，保留既有方向键/Home/End、选中状态和面板标签。关闭的折叠与未选中的 tabs 仍属于完整文档复制内容。

### 章节提纲

当前可见 H2/H3 标题至少六个时，提供按正文顺序排列的静态提纲；4/5 节短文不显示。提纲只列当前可见主阅读流的章节，避免把隐藏折叠或非当前 tabs 的标题描述成可定位对象。使用默认收起的原生 `details/summary`，摘要为“章节概览 · N 节”；展开内容为普通列表文字，不绘制链接状态、当前位置、进度条或“已定位”通知。概览的展开状态只属于当前挂载，不写入持久状态或完整复制文本。

动态定位需要另外证明 iframe 自身滚动所有权、标题滚动与焦点成功；在宿主滚动未经验证的 Phase 2A 中采用静态提纲。不得读取或操作父 DOM，不用本地 iframe 的成功外推私人宿主。

### 完整复制

“复制完整文档”使用已验证文档的同源可读 fallback，不能读取当前 DOM 的 `innerText`。完整复制覆盖首尾正文、关闭折叠、全部 tabs、公式原文及组件说明；包含文档固定题设，不能把当前实验状态默认为永久题设。Quiz 的未提交评分键和解释不进入复制文本。

按钮启动真实 Clipboard 写入，Promise 成功后才提示成功。API 不存在、权限拒绝或写入失败时，显示带标签的只读 textarea 供手动选择，并明确自动复制未成功。用户可以关闭该区域回到复制控件。手动选择文本不触发成功声明。文档更换或销毁后的异步结果不得更新旧界面。

## 5. 窄屏、键盘和主题

grid 的可收缩列与 `min-width:0` 保证内容参与宽度约束。表格、代码、展示公式保留局部横向滚动；仅实际可见且 `scrollWidth > clientWidth + 1` 的区域显示下方“横向滚动查看完整…”提示、region 语义与 Tab 停靠。未溢出或隐藏内容没有提示及额外停靠点。共享 ResizeObserver、窄范围主题观察、字体和现有内容更新路径负责重测，销毁时取消回调；提示不覆盖正文。不以 `body { overflow-x:hidden }` 遮住布局错误。长词允许换行，代码块保留源格式。手动复制文本域为全宽、至少 12rem 高，可纵向调整大小；状态提示和工具按钮允许换行。

所有真实操作使用原生可聚焦控件；44px 包含滑块的可交互高度。焦点圈覆盖键盘操作和局部滚动区域。静态提纲没有多余 Tab 停靠点。reduced motion 下禁用文档范围内的 CSS animation、transition 和平滑滚动；不添加自动播放装饰。

深浅主题分别检查正文、辅助文本、提示、边界、焦点、图形标注及当前数值。暗色卡片与文档外层均透明，不把浅色阴影或硬编码背景带入深色主题。

## 6. 反例与对应修正

| 反例 | 为什么有害 | 本轮选择 |
|---|---|---|
| 每段解释都是彩色卡片 | 分隔线比论证更抢注意力，连续关系被切碎 | 正文 + 章节标题 + 少量有标签的 callout |
| 把当前滑块值写进“已证明最大值” | 把实验状态与固定结论混为一谈 | 固定推导与当前实验独立标记 |
| 给立场添加“可信度 92%”或投票 | 没有数据与方法却制造权威感 | 显示前提、理由、推论和反例目标 |
| 目录按钮点击只改提示“已定位” | 没有滚动/焦点证据却宣称成功 | 静态提纲；将动态定位列为未来需证明事项 |
| 复制 `innerText` 后显示“已复制全部” | 丢失关闭折叠/隐藏 tab，并混入工具条文字 | 复制同源完整 fallback；错误时手动选择 |
| 用全页横向裁切解决长公式 | 内容丢失且键盘无法取得隐藏部分 | 公式/代码/表格自身成为可滚动区域 |
| 把短答也转为长文原型 | 增加不必要的阅读操作 | G06 展示原生文本条件 |

## 7. 验收任务与证据边界

| 用户任务 | 可观察通过条件 | 证据要求 |
|---|---|---|
| G01 找到最优条件 | 正文能读到固定 `h=3 cm` 与 `3√3 cm²` | 编译/fallback 断言 + 截图 |
| G01 探索并解释差异 | 键盘改变 `h/r` 后 SVG、数值及单位同步，固定最优推导不变 | 浏览器真实 input/change 与独立 oracle |
| G01 非法输入恢复 | 原下溢反例被明确拒绝，没有图形/控件/错误状态残留 | 原反例、合法 tiny/large 与重新挂载回归 |
| G04 找隐含前提 | 事实与价值判断、隐含前提的编号明确 | 原型内容审核 |
| G04 找反例和未解决问题 | disclosure 可键盘展开，反例指向具体推论 | 浏览器键盘记录 + 展开截图 |
| G05 定位证据与限制 | 八节顺序、证据编号和限制可读；提纲清楚标为静态 | 内容断言 + 代表性截图 |
| G05 复制完整文档 | 隐藏折叠与全部 tabs 保留、无 Quiz 评分信息 | Clipboard 成功/拒绝/缺失分支及文本逐项断言 |
| 窄屏阅读 | 320/390/768/1024px 无整页横向溢出，长公式/表格/代码可局部滚动 | 深浅主题截图 + 实际 overflow 测量 |
| 键盘与焦点 | 控件和滚动区能到达、焦点可见、目标尺寸正确 | 浏览器交互与计算样式；截图辅助 |
| 读屏 | 名称、顺序、状态反馈与阅读连续性合理 | 人工读屏未执行时必须 UNKNOWN |
| 宿主协作 | 真实宿主的滚动、主题、焦点与复制均可靠 | 私人宿主不在本轮权限内，UNKNOWN |

**设计判断：** 18px 正文、32px 标题前总间隔、中性比较卡和去背景 callout 预计更易连续阅读；没有用户研究，不能声明理解速度、记忆或完成率已经提高。

**B1 前态观察：** 从起点提交生成资源捕获的本地预览，正文 computed font-size 为 16px；callout 有明显灰色底。前态资源与截图保存在本轮隔离工作区的本地审查包中，用同一输入比较时才能归因样式变化。该观察没有证明 B1 功能失败，也不是后态已通过的证据。

**源码可确认：** 改动限定 Document 样式；既有组件运行时和颜色 token 复用；外层透明；无新的渲染引擎。源码可证明意图与范围，不能单凭 CSS 声明确认没有溢出或对比度已合格。

**实际证据：** 当轮截图、布局测量、键盘/复制行为和回归日志由 Phase 2A 验收报告统一记录。B1 截图只能作为前态，历史 PASS 不能证明当前实现。没有运行的人工读屏、私人宿主和用户理解度测量均保留 UNKNOWN；本规范不预填 PASS。

## 8. Phase 2A 停止点

三个原型与原生对照完成本地验证、截图和提交后等待视觉审核。后续若批准 Phase 2B，可复用这些 token 和真实 fixture，构建完整 G01–G08 离线 Gallery 并验证 `file://`，但不在本规范的实施范围内。版本升级、默认路由变更、私人插件安装、部署和发布均需后续对应授权。
