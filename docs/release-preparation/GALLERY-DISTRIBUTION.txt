ChatUI offline Gallery — local release candidate, not published

Open gallery/index.html directly, or from this directory run:
  python3 -m http.server 4173 --bind 127.0.0.1 --directory gallery
Then open http://127.0.0.1:4173/index.html. Stop the local server with Ctrl-C.

No npm install, model API key, MCP connection or remote font is required.
This is a fixed synthetic demonstration, not a ChatGPT plugin installer or
proof of live model behavior. Use gallery/README.md for controls and limits.
