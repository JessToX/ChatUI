# ChatUI 0.7 · 截图对齐规范

依据本次于 2026-10-05 收到的十张用户截图；这些视觉要求优先于通用 UI 推荐。日期表示本次收到样本的时间，不推断截图内容的发生日期。

- 外层透明，正文在卡片外连续推进，不复制 ChatGPT 的导航、输入框或浏览器外壳。
- 深色预览采用黑底白字；浅色根据宿主主题切换。卡片透明、1px 中性边框、18px 圆角。
- 18px 正文 / 1.7 行高；窄屏 16px。标题 24–28px，主数字 48–54px，公式约 26px。
- 卡片内边距 22px（窄屏 18px）；内容块间距 28px，段内间距 12px；细分隔线不抢注意力。
- 蓝色表示比较和可探索关系，绿色表示进展和结论，橙色表示当前阶段或辅助量；颜色必须配有标签。
- 对照卡等宽并列，窄屏纵向；推导用编号和公式，时间线用编号轨道、日期与状态。
- 风格档案保留英文 eyebrow、大中文名、英文副标题、蓝色标签与分隔线。
- 节奏条只表示定性关注度，不显示伪造百分比或字数测量。
- 图解直接标注对象、方向和单位；提供文字描述。安全 MathML/SVG 数据，不接受 HTML/JS。
- 控件有可见标签、键盘操作、焦点圈，触摸目标至少 44px；不预填测验得分。
- 更新是完整新快照；只有相同内容身份的真实交互状态能恢复。

本地验收：学习 / 写作 / 进展 × 深浅主题 × 桌面 / 360 CSS px；本地预览不替代普通 Chat 自动选用和实际显示的验收。
